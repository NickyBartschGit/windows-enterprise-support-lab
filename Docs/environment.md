# Lab Environment

# Overview

This project uses a simulated small-business IT environment created for hands-on Windows support, Microsoft Entra ID administration, networking, security, and troubleshooting practice.

The fictional organization used throughout the lab is **Bartsch Technologies**.

No production systems, real employee accounts, or real organizational data are used in this project.

# Organization

The simulated organization contains four departments:

- Sales
- Finance
- Operations
- Human Resources

Fictional employee accounts were created for each department to simulate common identity, access, authentication, and technical support scenarios.

# Microsoft Entra ID

Microsoft Entra ID was used to practice cloud identity and access administration.

Department security groups include:

- SG-Sales
- SG-Finance
- SG-Operations
- SG-HR

These groups were used to simulate group-based access to departmental applications and resources.

Lab exercises included:

- User account administration
- Security group membership
- Password resets
- Identity verification procedures
- Authentication troubleshooting
- Group-based access troubleshooting
- Least-privilege access concepts

# Windows Workstation

A Windows 11 workstation was used for endpoint troubleshooting exercises.

Windows tools and features used during the lab include:

- PowerShell
- Command Prompt
- Task Manager
- Event Viewer
- Windows Services
- Windows Storage
- NTFS permissions
- Advanced Security Settings
- Network configuration tools

## Security

The lab follows several basic support security principles:

- Verify user identity before credential changes
- Confirm authorization before granting access
- Follow least-privilege principles
- Escalate sensitive access changes when approval is required
- Distinguish technical capability from authorization
- Avoid exposing credentials or sensitive system information in documentation

All employees, incidents, departments, and business scenarios in this project are fictional and were created specifically for technical training.
